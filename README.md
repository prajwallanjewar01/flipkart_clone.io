# 🛒 Flipkart Clone Website

A simple clone of the Flipkart e-commerce website, built to demonstrate core front-end and basic backend logic. This project replicates the user interface and navigation of Flipkart, offering multiple pages such as home, login, cart, and seller dashboard.

---

## 🧾 About

A front-end focused Flipkart clone created for learning and practicing HTML, CSS, and basic JavaScript with additional backend simulation using Java. Built and tested in Visual Studio Code.

---

## 📁 Project Structure

flipkart-clone/
│
├── index.html # Home page
├── cart.html # Shopping cart
├── grocery.html # Grocery section
├── login.html # User login page
├── pg.html # Payment gateway placeholder
├── seller.html # Seller dashboard
├── loginstyle.css # CSS for login page
├── style.css # Main stylesheet
├── .hintrc # HTMLHint configuration file
├── img/ # Folder for images
└── README.md # Project documentation
